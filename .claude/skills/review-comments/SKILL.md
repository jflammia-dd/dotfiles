# Respond to Confluence Review Comments

## Rules
1. Read ALL comments on the page first. Skip already-resolved ones.
2. Address each commenter DIRECTLY (second person: "you", "your").
3. Apply /justins-voice rules to every response (no em dashes, no Oxford commas, no semicolons joining clauses).
4. For each comment: draft the response, show it for approval, THEN post.
5. If a comment requires a doc edit, make the edit FIRST, then respond referencing the change.
