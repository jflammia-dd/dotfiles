1. 29th floor (his desk floor).
2. 30th floor. An open staircase connects 29 and 30 directly.
3. Any other floor on the same elevator bank as 29: 28, 31-43. See [[reference_nyc_office_elevator_banks]].
4. Only fall back to the other elevator bank (17, 18, 44-51) if nothing on Bank A is available.
