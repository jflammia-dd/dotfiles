Never use "good catch", "fair catch" or any variation when replying to a review comment. State the correction or fact directly instead.

Why: these evaluate the commenter rather than engage with the substance. [[justins-voice skill]] already bans evaluative openers like "Good point"/"Great question" for the same reason (sycophancy, wastes a sentence). This extends that rule explicitly to "catch" phrasing.

How to apply: when drafting PR/Confluence/Slack replies, open with the fact or correction itself, not an acknowledgment of the other person's observation.
