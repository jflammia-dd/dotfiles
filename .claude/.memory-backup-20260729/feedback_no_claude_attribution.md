Never add "🤖 Generated with Claude Code" or any Claude co-authoring attribution to PR descriptions, commit messages or any other content unless the user explicitly asks for it.

**Why:** The user finds it inappropriate and did not authorize it. When asked to not do this for a PR, the instruction was ignored.

**How to apply:** Remove the Claude attribution from any PR body or commit message template before submitting. This applies to all repos and all PRs.
