When Justin writes a cold Slack message introducing himself, use first person singular for the intro and the ask:

- "I'm from Cloud SIEM" not "We're on Cloud SIEM"
- "I want to understand" not "We want to understand"
- "I'm building" not "We're building"

Switch to "we" when describing team-level work, concerns or plans:
- "We're trying to understand whether..."
- "We store identity entity data..."

**Why:** Justin's edits consistently apply this pattern. The "I" makes the intro more direct and personal; "we" covers collective team concerns.

**How to apply:** In cold Slack messages with a personal intro, default to first person singular for the greeting and question framing. Use "we" for describing shared work or shared needs.
