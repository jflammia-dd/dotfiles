When a doc is no longer relevant or helpful due to fast-moving project decisions, retire it (delete it) rather than spending time updating it.

**Why:** The ERS/Entity Context work moves fast. Decision flow docs, option comparison docs and similar artifacts become misleading once the decision is made. Maintaining them creates more work than value.

**How to apply:** Proactively flag stale docs when they become superseded. When the user says to retire one, delete the file outright. Don't convert to "archived" status or add superseded headers. Just remove it.
