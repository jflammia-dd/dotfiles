description: When asked to write a new document, always create a new file with a distinct name. Never overwrite an existing document.

When the user asks to "write a new document" or "write it as a new document," create a new file. Do not replace or overwrite the existing file at the same path.

**Why:** In this session, the user asked for a new 1-page leadership summary of the ERS Resolution Matrix. I replaced the full-detail `ERS - Resolution Matrix.md` with the short version, destroying the detailed reference content. The user was upset. The correct action was to create `ERS - Delivery Plan.md` as a separate file.

**How to apply:** When the request says "write a new document," ask yourself: is there an existing document at the target path? If yes, choose a new filename. The original stays intact. Reference it from the new doc if appropriate.
