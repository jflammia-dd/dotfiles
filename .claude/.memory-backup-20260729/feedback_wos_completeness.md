When a captured item turns out to be already done or when resolving an item, close it out everywhere in the vault automatically. Do not stop after finding it in one place and reporting "already done."

**Why:** The whole point of Work OS is to offload tracking. If the user has to notice and ask for cleanup, the system has failed its purpose.

**How to apply:** Any time an item is marked complete, resolved, or found to already be done, search all active project status pages, people pages and open item lists for any reference to it. Update every one before reporting back. The vault must be left fully consistent.
