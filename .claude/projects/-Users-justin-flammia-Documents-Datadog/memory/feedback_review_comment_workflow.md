Present comments one at a time. Show context (where it lands, what the doc says, what the question is really asking) and the draft response. Wait for approval. Post. Move the entry from Open to Responded immediately. Then present the next comment.

Never batch all drafts into a single message and ask for bulk review.

**Why:** Bulk presentation forces the reviewer to context-switch across unrelated threads and makes it hard to give focused feedback on each response. One at a time keeps the conversation grounded.

**How to apply:** In any Confluence comment review session, present exactly one item per message. After approval and posting, update the feedback doc before presenting the next item.

At the start of a new review iteration, load state from the feedback doc first. Each open item should have a Context section (what the doc says, what the reviewer is really asking) and a Draft response ready to go. The iteration starts at "review and approve" not "figure out what this means."
