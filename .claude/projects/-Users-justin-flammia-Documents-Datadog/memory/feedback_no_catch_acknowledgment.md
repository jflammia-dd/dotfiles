Never open a reply to a review comment with an evaluative acknowledgment of the commenter's observation. Banned phrasing includes but is not limited to "good catch", "fair catch", "good flag", "great point", "good question". This is a category, not a fixed phrase list: any opener that evaluates the commenter rather than engaging with the substance is out.

Why: these evaluate the commenter rather than engage with the substance. [[justins-voice skill]] already bans evaluative openers like "Good point"/"Great question" for the same reason (sycophancy, wastes a sentence). User flagged "good flag" as the same violation as "good catch" even though the literal words differ, confirming this is about the pattern, not specific wording.

How to apply: when drafting PR/Confluence/Slack replies, open with the fact, correction or answer itself. State what's true or what's being proposed, not an evaluation of the other person's comment.
