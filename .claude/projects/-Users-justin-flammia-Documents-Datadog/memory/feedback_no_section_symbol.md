Never use the section symbol (§) to refer to a document section. Write out the section's actual name or heading instead (e.g. "the Cloud Provider Entity Types (AWS) section" rather than "§3.2").

**Why:** The user flagged that many readers outside legal contexts don't recognize what § means. It reads as jargon rather than a clear reference.

**How to apply:** Applies to any human-facing prose: Confluence comments, Slack messages, doc edits, PR descriptions. When citing a section, resolve its actual heading text from the document and name it directly, not by symbol or number shorthand.
