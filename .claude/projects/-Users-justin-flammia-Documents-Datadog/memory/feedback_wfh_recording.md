---
name: WFH recording convention
description: Only record WFH when it deviates from normal cadence, not routine WFH days
type: feedback
---

Only record WFH entries in office tracking when something deviates from the normal routine. Examples: bad weather, NJT/transit disruptions, illness, appointments.

**Why:** Routine WFH is the default pattern, not an exception. The tracking exists for compliance audit purposes, so only notable deviations warrant a record.

**How to apply:** The `/wfh` command should always require a reason. Never add a WFH entry without one. Do not prompt the user to log WFH on days they worked from home without a notable reason.
